# Space Missions Analysis (1957 - 2020)

This project explores the history of space exploration from the beginning of the Space Race to the present day. 
Using data from nextspaceflight.com, I analyze trends in mission success rates, costs, and the dominance of different space organizations.

## Dataset Features
- mission_launches.csv: Contains data on launch organizations, locations, dates, rocket status, price, and mission success.

## Key Questions Explored
- Who launched the most missions in any given year?
- How has the cost of a space mission varied over time?
- Which months are the most popular for launches?
- Have space missions gotten safer over the decades?

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Plotly (Choropleth, Sunburst, and Segmented Bar Charts)
